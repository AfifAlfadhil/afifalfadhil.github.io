# Portofolio Naufal ’Afif Alfadhil

Situs statis tanpa build step. Jalankan `npx serve .` atau buka `index.html`.

- `index.html`: seluruh konten. Teks proyek diedit langsung di sini.
- `css/style.css`: gaya (font variabel Bricolage Grotesque).
- `js/main.js`: hero interaktif, kalimat yang menyala saat scroll, folder proyek (scroll vertikal menggerakkan kartu horizontal dengan efek kipas), akordeon, email magnetik.
- `assets/`: gambar.

## Mengisi tangkapan layar proyek
Di tiap `.shot-ph` di `index.html` ada komentar berisi tag `<img>` siap pakai. Simpan gambar di `assets/` lalu ganti komentarnya dengan tag tersebut.

## Mengisi link deployment
Cari komentar `Demo:` di tiap proyek dan eksperimen, lalu tempel tautan `<a>` di sana.

Efek folder hanya aktif di layar lebar dan semua animasi mati jika perangkat memakai prefers-reduced-motion.
